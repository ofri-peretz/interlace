# AI-SDLC philosophy: follow Anthropic, prove it

Interlace OSS builds with coding agents. We do not invent our own doctrine for that. We follow
what Anthropic publishes about verifying agent work, building evaluations, keeping agent memory
and learning from incidents. We then hold each concept to one test: **a file, check or number in
a repository shows we do it.** A concept without a proof is marked as a gap. It is never written
up as done.

Sources, read 2026-11-25:

- [Claude Code best practices](https://code.claude.com/docs/en/best-practices) (verification)
- [Building strong safety evaluations](https://www.anthropic.com/research/building-strong-safety-evaluations) (E)
- [Components of agent memory](https://www.anthropic.com/research/components-of-agent-memory) (M)
- [April 23 postmortem](https://www.anthropic.com/research/april-23-postmortem) (P)

Status: **Held** = a proof exists and is enforced · **Partial** = a proof exists but has a gap ·
**Gap** = nothing yet. Paths are in [ofri-peretz/eslint](https://github.com/ofri-peretz/eslint)
unless noted.

## Gaps, ordered by what they would change

1. **The reviewer comparison is underpowered (E13, E14).** Ten PRs cannot separate 40% from
   50% signal. Report a confidence interval, and extend the comparison window until it can
   decide.
2. **No human check of the model labeller (E12).** Hand-label 20 findings and report agreement
   with the model labels before trusting either number.
3. **The stale CWE-089 corpus (E11).** Add the missing import, so the flagship benchmark scores
   the current package.
4. **Memory is never measured or consolidated (M2, M6).** Schedule the consolidation skill, and
   record what it corrected.
5. **No multi-turn regression test for hooks (P2).** Replay a recorded session through the Stop
   hooks and assert the decisions.

Each gap closes the way everything above did: with a file, check or number that someone else can
re-run, and a test that fails without it.
