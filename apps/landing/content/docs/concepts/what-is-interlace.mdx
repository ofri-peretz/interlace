Interlace is a small set of open-source tools for JavaScript and TypeScript developers. Each one solves one problem: finding security bugs, building a CLI, keeping a Serverless project clean. You install each one on its own.

What they share is a set of rules:

- **Numbers you can check.** Every comparison ("faster than X", "fewer dependencies than Y") points to a versioned benchmark file you can rerun. No claim ships without a result behind it.
- **One way to read the docs.** Every product site uses the same theme, navigation and components, synced from one baseline, so once you know one site you know them all.
- **Few dependencies.** A dependency is added only when we can say why. Less to install, less to audit.

## What the name means

Interlace means weaving. The products are separate threads, but they share a pattern: an idea proven in one product becomes the template for the next. For example, `@interlace/serverless-api-gateway-caching` deletes what it created when you remove it, and that pattern is the template for the plugins that follow.

## Who is behind it

Interlace is independent, MIT-licensed and built in the open by [Ofri Peretz](https://ofriperetz.dev). It answers to the people who use it, not to investors. If it ever becomes a company, that will follow the work, not lead it.

## What it is not

- **A framework you adopt.** You don't pick "Interlace"; you pick the plugin or tool that solves your problem.
- **A bundle.** There is no umbrella package. You install `eslint-plugin-jwt`, `burgee` or `@interlace/serverless-api-gateway-caching` directly.
