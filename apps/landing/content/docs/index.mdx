Interlace is a set of free, MIT-licensed tools for JavaScript and TypeScript developers, built in the open by Ofri Peretz. Every claim on these sites comes from a test or a benchmark you can run yourself.

## The products

| Product                | What it does                                                        | Site                                                             |
| ---------------------- | ------------------------------------------------------------------- | ---------------------------------------------------------------- |
| ESLint plugins         | Find security bugs and mistakes, including in AI-written code       | [eslint.interlace.tools](https://eslint.interlace.tools)         |
| burgee                 | A CLI framework for Node.js, for humans and agents alike            | [burgee.interlace.tools](https://burgee.interlace.tools)         |
| Serverless plugins     | API Gateway caching and per-function IAM roles that clean up after themselves | [serverless.interlace.tools](https://serverless.interlace.tools) |
| Interlace UI           | The React design system these sites are built with                  | [ds.interlace.tools](https://ds.interlace.tools)                 |

The ESLint plugins are **unscoped**: you install `eslint-plugin-jwt`, with no `@interlace/` prefix, because ESLint finds plugins by that name. The only scoped ESLint package is `@interlace/eslint-devkit`, the toolkit the plugins are written with.
