Interlace is a family of TypeScript-native developer tools. Every plugin we ship is **measured against alternatives**, every claim is backed by a versioned benchmark, and every dependency we add is one we can defend.

## The products

| Product                   | Where to read                | Subdomain                                                        |
| ------------------------- | ---------------------------- | ---------------------------------------------------------------- |
| `eslint-plugin-*`         | ESLint plugin suite          | [eslint.interlace.tools](https://eslint.interlace.tools)         |
| `@interlace/serverless-*` | Serverless Framework plugins | [serverless.interlace.tools](https://serverless.interlace.tools) |
| `@interlace/ui`           | Design system + registry     | [ds.interlace.tools](https://ds.interlace.tools)                 |

The ESLint plugins are **unscoped** — you install `eslint-plugin-jwt`, with no `@interlace/` prefix — because ESLint resolves plugins by that name convention. The only scoped ESLint package is `@interlace/eslint-devkit`, the authoring toolkit.
