## What the baseline says

1. **Before any work, a session already holds 74k–110k tokens** (eslint 106k, burgee 101k,
   agents 74k). The repos' own CLAUDE.md chains are 8–25 lines, so nearly all of it is
   user-level setup: the skill list, plugin agents, MCP tool definitions and the memory index.
   Context optimization pays off there first, not in the repo files. Target: under 50k.
2. **The cache works.** 94–99% of input tokens come from the prompt cache in every active repo.
   Keep CLAUDE.md, tools and MCP servers stable within a session ([E-28](EVIDENCE.md#e-28)).
3. **What a merged PR costs in fresh tokens:** eslint 212k, burgee 750k, agents 80k. Burgee
   costs 3.5× eslint per PR, so it is the first repo to profile.
4. **Subagents do most of the output** in eslint (69%) and burgee (77%), and almost none in
   agents (2%), where subagent-gateway's routing has not taken hold.
5. **Audit gaps:**
   - **blog** runs Claude review without an `AGENTS.md`. That is the one violation of the
     context gate.
   - **agents** has ready context but no review secret.
   - **subagent-gateway**, **workshops** and **impact-ingest** have no `CLAUDE.md`.
   - Four repos pin `eslint-plugin-import-next` 3 while 4 is out.
   - Evals and control bands exist only in eslint and burgee.
