New `@interlace/native` package: Interlace for React Native. It reads the same tokens as the web, generated from the brand CSS with a drift check. It has a theme provider with light, dark and system schemes, plus brand overrides. The pieces are `Text`, `Button`, `Stack`, `Card`, `Badge`, `Screen`, `ListRow`, `Reveal` and a UI-thread `Slider`. Two native games, `CloserGame` and `StreakStrip`, are scored by the web games' own models. `auditPalette` lets a consumer test its brand overrides against the WCAG floors.
