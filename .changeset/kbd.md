`Kbd` and `KbdGroup`: the shadcn core `kbd` item in Interlace tokens. `Kbd` is a native `<kbd>` with `sm` (default) and `md` sizes; `KbdGroup` nests keys inside one `<kbd>` for a chord (`⌘ K`) or a sequence (`G` then `I`). Server component.
