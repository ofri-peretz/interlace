The rest of the live activities now run on a live room with the room's guarantees, the way the Q&A board, reactions, hands and spectrum do. Fourteen hooks (`useRoomRating`, `useRoomQuadrant`, `useRoomPin`, `useRoomRanking`, `useRoomPoints`, `useRoomDots`, `useRoomPrediction`, `useRoomTypeAnswer`, `useRoomCloud`, `useRoomWall`, `useRoomReflection`, `useRoomNotes`, `useRoomGoal`, `useRoomReveal`) give the props for `Rating`, `Quadrant`, `PinDrop`, `RankChoices`, `PointsSplit`, `DotVote`, `Prediction`, `TypeAnswer`, `WordCloud` and `WordEntry`, `TextWall`, `ReflectionCard`, `NoteBoard`, `RoomGoal` and `PictureReveal`, which are unchanged; the rules the host runs are `ratingActivity`, `quadrantActivity`, `pinActivity`, `rankingActivity`, `pointsActivity`, `dotsActivity`, `predictionActivity`, `typedActivity`, `cloudActivity`, `wallActivity`, `notesActivity`, `goalActivity` and `revealActivity`. A move is applied once however often it arrives, a phone sends it again until the host's state shows it, a refreshed host gets everything back, and a player who is removed disappears from what every screen reads. Typed text passes the text-safety checks (and the consumer's blocklist) on the host, and the open wall holds new posts for the host's review by default. A private reflection never leaves the phone; one the writer shares goes to the wall.

`useSubmit` is now exported from `use-live-activities`. These activities are not anonymous: the room holds each answer by player id, which the host and a client reading the room's state can see; screens show shares, not names.
